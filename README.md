# Torn PDA Wage Calculator

A Torn PDA userscript for company directors that suggests employee wages using work stats and effectiveness.

## Install in Torn PDA

Use this raw script URL:

`https://raw.githubusercontent.com/chadgian/torn-pda-wage-calculator/main/ghost-byte-wage-calculator.user.js`

In Torn PDA, open the userscript manager, choose **Add from URL**, paste the URL, and save it with injection time set to **End**.

## Features

- Movable floating Wage Calc button
- Configurable wage models and detailed setting help
- Employee exclusions
- Optional visible wage-field autofill without submitting changes
- Informational Cyber Cafe position suggestions
- CSV and wage-list copying

## Privacy

The script uses the Torn API key supplied locally by Torn PDA. Do not hardcode or publish a personal API key.
